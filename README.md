# React Travel Website

A responsive travel website built with React as part of my practice with React components, routing and responsive web design.

This project was created by following a YouTube tutorial and helped me gain more hands-on experience building and structuring a React application.

## Features

* Responsive navigation bar
* Hero section with video or image background
* Reusable card components
* Multiple pages using React Router
* Travel destination cards
* Responsive design for different screen sizes

## Technologies Used

* React
* JavaScript
* HTML
* CSS
* React Router
* Create React App

## Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will run at `http://localhost:3000`.
