# React Travel Website

A responsive travel website built with React as part of my practice with React components, routing, responsive web design and user authentication.

This project was initially created by following a YouTube tutorial and was later extended with additional functionality, including Firebase Authentication.

## Features

* Responsive navigation bar
* Hero section with video background
* Reusable React components
* Multiple pages using React Router
* Travel destination cards
* Responsive design for different screen sizes
* User registration with email and password
* User sign in and logout
* Firebase Authentication
* Dynamic navigation based on authentication status
* Automatic redirect after successful sign in

## Technologies Used

* JavaScript
* HTML
* CSS
* React Router
* Firebase Authentication

## Authentication

The application uses Firebase Authentication to provide email and password authentication.

Users can:

* Create a new account
* Sign in with an existing account
* Sign out
* Remain authenticated while navigating through the application

The navigation bar automatically updates depending on whether a user is signed in.
